# 海浪间的庇护所

2026-11-22

西班牙坎塔布里亚自治区的圣胡斯塔隐修院与小教堂

今天图片中的圣胡斯塔隐修院建于16世纪，坐落在西班牙坎塔布里亚自治区北部崎岖海岸的悬崖间，俯瞰坎塔布连海上翻涌的浪涛。这座小教堂部分嵌入岩石中，与圣胡斯塔与圣鲁菲娜的圣髑有关，后来成为一处朝圣地。它受到庇护的石墙，与四周汹涌的海浪和嶙峋的悬崖形成鲜明对比。

坎塔布里亚自治区的圣胡斯塔隐修院依崖而建，朝南的门上方有一扇小方窗，为堂内引入光线。
